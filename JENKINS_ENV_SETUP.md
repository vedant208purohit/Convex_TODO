# Jenkins Environment Setup — pos-default (Store POS)

This document explains exactly which environment variables Jenkins must inject
**before** running `npm run build` to ensure Clerk authentication works correctly
in production. Without these variables, Clerk falls back to its default hosted UI
at `accounts.clerk.com` instead of using the custom sign-in page.

## Why This Matters

`NEXT_PUBLIC_*` variables are **baked into the Next.js bundle at build time**.
Changing them after the build has no effect. Jenkins must inject them into the
build environment **before** the `npm run build` step.

## Required Environment Variables

| Variable | Required | Description |
|---|---|---|
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | ✅ Yes | Clerk publishable key (`pk_live_...` or `pk_test_...`) |
| `CLERK_SECRET_KEY` | ✅ Yes | Clerk secret key — server-side only (`sk_live_...`) |
| `NEXT_PUBLIC_CLERK_SIGN_IN_URL` | ✅ **Critical** | Must be `/sign-in` — tells Clerk your app has a custom sign-in page |
| `NEXT_PUBLIC_CLERK_SIGN_UP_URL` | ✅ **Critical** | Must be `/sign-up` — tells Clerk your app has a custom sign-up page |
| `NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL` | ✅ Yes | Must be `/` — where to go after sign-in if no redirect target |
| `NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_REDIRECT_URL` | ✅ Yes | Must be `/` — where to go after sign-up if no redirect target |
| `NEXT_PUBLIC_CONVEX_URL` | ✅ Yes | Production Convex deployment URL |
| `NEXT_PUBLIC_CONVEX_SITE_URL` | ✅ Yes | Production Convex HTTP Actions URL |
| `CLERK_JWT_ISSUER_DOMAIN` | ✅ Yes | Your Clerk domain (used by Convex for token verification) |
| `NEXT_PUBLIC_DEFAULT_APP_URL` | ✅ Yes | This app's public production URL |

## Jenkins Configuration Methods

### Option A — Pipeline `environment {}` block (Declarative Pipeline)

```groovy
pipeline {
  agent any

  environment {
    // Clerk — CRITICAL for custom sign-in UI
    NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY = credentials('pos-default-clerk-publishable-key')
    CLERK_SECRET_KEY                  = credentials('pos-default-clerk-secret-key')
    NEXT_PUBLIC_CLERK_SIGN_IN_URL     = '/sign-in'
    NEXT_PUBLIC_CLERK_SIGN_UP_URL     = '/sign-up'
    NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL = '/'
    NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_REDIRECT_URL = '/'
    CLERK_JWT_ISSUER_DOMAIN           = credentials('pos-default-clerk-jwt-domain')

    // Convex
    NEXT_PUBLIC_CONVEX_URL            = credentials('pos-default-convex-url')
    NEXT_PUBLIC_CONVEX_SITE_URL       = credentials('pos-default-convex-site-url')

    // App
    NEXT_PUBLIC_DEFAULT_APP_URL       = 'https://your-production-store-domain.com'
  }

  stages {
    stage('Install') {
      steps { sh 'npm ci' }
    }
    stage('Build') {
      steps { sh 'npm run build' }
    }
    stage('Start') {
      steps { sh 'npm start' }
    }
  }
}
```

### Option B — `.env.production` file generated by Jenkins before build

If you use a shell script in Jenkins to write a `.env.production` file:

```bash
cat > .env.production << EOF
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=${CLERK_PUBLISHABLE_KEY}
CLERK_SECRET_KEY=${CLERK_SECRET_KEY}
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up
NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL=/
NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_REDIRECT_URL=/
CLERK_JWT_ISSUER_DOMAIN=${CLERK_JWT_DOMAIN}
NEXT_PUBLIC_CONVEX_URL=${CONVEX_URL}
NEXT_PUBLIC_CONVEX_SITE_URL=${CONVEX_SITE_URL}
NEXT_PUBLIC_DEFAULT_APP_URL=${APP_URL}
EOF
npm run build
```

> **Note:** Next.js loads `.env.production` automatically during `next build`.
> Do NOT commit this file — add it to `.gitignore`.

## Verifying the Setup

After a Jenkins build, the custom Clerk sign-in page at `/sign-in` should:
1. Render your **dark-themed custom UI** (dark background, indigo buttons)
2. **Not** redirect to `accounts.clerk.com`
3. Correctly redirect to `/` after a successful sign-in

To diagnose issues, add this temporary debug step to the Jenkins pipeline:

```groovy
stage('Verify Clerk Env') {
  steps {
    // Shows first 5 chars only — confirm it's set without leaking the key
    sh 'echo "SIGN_IN_URL=${NEXT_PUBLIC_CLERK_SIGN_IN_URL}"'
    sh 'echo "PK_SET=$(echo $NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY | cut -c1-5)"'
  }
}
```

## Checklist Before Each Deployment

- [ ] `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` is set in Jenkins env
- [ ] `CLERK_SECRET_KEY` is set in Jenkins env (as a secret credential)
- [ ] `NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in` is set
- [ ] `NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up` is set
- [ ] `NEXT_PUBLIC_CONVEX_URL` points to production Convex deployment
- [ ] `npm run build` runs **after** env vars are injected (not before)
