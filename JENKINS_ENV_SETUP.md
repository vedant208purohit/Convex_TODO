# Jenkins Environment Setup — pos-master (Admin Control Plane)

This document explains exactly which environment variables Jenkins must inject
**before** running `npm run build` to ensure Clerk authentication works correctly
in production. Without these variables, Clerk falls back to its default hosted UI
at `accounts.clerk.com` instead of using the custom sign-in page.

## Why This Matters

`NEXT_PUBLIC_*` variables are **baked into the Next.js bundle at build time**.
Changing them after the build has no effect. Jenkins must inject them into the
build environment **before** the `npm run build` step.

## Required Environment Variables

| Variable | Required | Description |
|---|---|---|
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | ✅ Yes | Clerk publishable key (`pk_live_...` or `pk_test_...`) |
| `CLERK_SECRET_KEY` | ✅ Yes | Clerk secret key — server-side only (`sk_live_...`) |
| `NEXT_PUBLIC_CLERK_SIGN_IN_URL` | ✅ **Critical** | Must be `/sign-in` — tells Clerk your app has a custom sign-in page |
| `NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL` | ✅ Yes | Must be `/` — where to go after sign-in if no redirect target |
| `CLERK_JWT_ISSUER_DOMAIN` | ✅ Yes | Master app's Clerk domain (for Convex token verification) |
| `DEFAULT_CLERK_JWT_ISSUER_DOMAIN` | ✅ Yes | Default app's Clerk domain (for cross-app token verification) |
| `NEXT_PUBLIC_CONVEX_URL` | ✅ Yes | Production Convex deployment URL for master app |
| `NEXT_PUBLIC_CONVEX_SITE_URL` | ✅ Yes | Production Convex HTTP Actions URL |
| `CONVEX_MANAGEMENT_API_KEY` | ✅ Yes | Convex Management API key (server-side only) |
| `CONVEX_MANAGEMENT_TOKEN` | ✅ Yes | Convex Management token (server-side only) |
| `CONVEX_TEAM_ID` | ✅ Yes | Convex Team ID for provisioning |
| `NEXT_PUBLIC_DEFAULT_APP_URL` | ✅ Yes | Production URL of pos-default store app |

## Jenkins Configuration Methods

### Option A — Pipeline `environment {}` block (Declarative Pipeline)

```groovy
pipeline {
  agent any

  environment {
    // Clerk — CRITICAL for custom sign-in UI
    NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY         = credentials('pos-master-clerk-publishable-key')
    CLERK_SECRET_KEY                          = credentials('pos-master-clerk-secret-key')
    NEXT_PUBLIC_CLERK_SIGN_IN_URL             = '/sign-in'
    NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL = '/'
    CLERK_JWT_ISSUER_DOMAIN                   = credentials('pos-master-clerk-jwt-domain')
    DEFAULT_CLERK_JWT_ISSUER_DOMAIN           = credentials('pos-default-clerk-jwt-domain')

    // Convex
    NEXT_PUBLIC_CONVEX_URL                    = credentials('pos-master-convex-url')
    NEXT_PUBLIC_CONVEX_SITE_URL               = credentials('pos-master-convex-site-url')
    CONVEX_MANAGEMENT_API_KEY                 = credentials('convex-management-api-key')
    CONVEX_MANAGEMENT_TOKEN                   = credentials('convex-management-token')
    CONVEX_TEAM_ID                            = credentials('convex-team-id')

    // App
    NEXT_PUBLIC_DEFAULT_APP_URL               = 'https://your-production-store-domain.com'
  }

  stages {
    stage('Install') {
      steps { sh 'npm ci' }
    }
    stage('Build') {
      steps { sh 'npm run build' }
    }
    stage('Start') {
      steps { sh 'npm start --port 3001' }
    }
  }
}
```

### Option B — `.env.production` file generated by Jenkins before build

```bash
cat > .env.production << EOF
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=${CLERK_PUBLISHABLE_KEY}
CLERK_SECRET_KEY=${CLERK_SECRET_KEY}
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL=/
CLERK_JWT_ISSUER_DOMAIN=${CLERK_JWT_DOMAIN}
DEFAULT_CLERK_JWT_ISSUER_DOMAIN=${DEFAULT_CLERK_JWT_DOMAIN}
NEXT_PUBLIC_CONVEX_URL=${CONVEX_URL}
NEXT_PUBLIC_CONVEX_SITE_URL=${CONVEX_SITE_URL}
CONVEX_MANAGEMENT_API_KEY=${CONVEX_MGMT_API_KEY}
CONVEX_MANAGEMENT_TOKEN=${CONVEX_MGMT_TOKEN}
CONVEX_TEAM_ID=${CONVEX_TEAM_ID}
NEXT_PUBLIC_DEFAULT_APP_URL=${DEFAULT_APP_URL}
EOF
npm run build
```

## Verifying the Setup

After a Jenkins build, visiting the deployed app URL should:
1. Redirect unauthenticated users to `/sign-in` on your **own domain** (not `accounts.clerk.com`)
2. Show your **dark-themed custom admin login page** (dark background, indigo buttons)
3. Redirect to `/` dashboard after successful sign-in

## Checklist Before Each Deployment

- [ ] `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` is set in Jenkins env
- [ ] `CLERK_SECRET_KEY` is set in Jenkins env (as a secret credential)
- [ ] `NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in` is set
- [ ] `NEXT_PUBLIC_CONVEX_URL` points to the **master** production Convex deployment
- [ ] `CONVEX_MANAGEMENT_API_KEY` and `CONVEX_MANAGEMENT_TOKEN` are set as secrets
- [ ] `npm run build` runs **after** env vars are injected (not before)
- [ ] `npm start` uses port `3001` (or match the `dev` script)
